# 功能说明

[← README](../../README.zh-CN.md) · [English](../en/features.md)

## 调音

调音页是一张卡片：上面是指针表，下面是 3+3 琴头。左边的弦钮是 4、5、6 弦，右边是 3、2、1 弦。

### 自动和手动

右上角的「自动 / 手动」开关切换模式，默认是**自动**。

- **自动**：随便弹一根弦，应用会找出当前定弦里最接近的那根，并点亮它的弦钮。
- **手动**：点一个弦钮，应用切到手动，把这根弦锁定为目标，同时播放它的参考音。把开关拨回去就回到自动。

手动模式下，琴头下方会出现一行工具：

- **持续参考音**：一直播放目标音，直到你停止。
- **− / +**：把目标弦升高或降低一个半音。

### 怎么看表盘

| 元素 | 含义 |
|---|---|
| 指针 | 和目标音的偏差，范围 −50 到 +50 音分 |
| 绿色区间 | 判定为准的范围，由容差决定 |
| 提示文字 | 「音偏低」（拧紧）、「音准已校准」或「音偏高」（放松），带箭头图标 |
| 实测频率 / 音分偏差 / 目标频率 | 检测到的频率、偏差音分、目标频率 |
| 波形条 | 实时输入信号 |

一根弦稳定调准后，它的弦钮上会显示对勾。顶栏的进度按钮可以清除所有对勾。

### 监听控制

- 打开应用就自动开始监听麦克风。点表盘左上角的「● 监听中」暂停，点「开始监听」恢复。
- 应用切到后台时会释放麦克风，回到前台后自动恢复。
- 输入过载时，提示文字会显示「声音过大，请离远些或弹轻些」。
- 页面底部的「没有吉他？试试内置试音模拟」会把一段模拟的吉他信号送进同一个检测器，可以选择琴弦和走音程度。

## 定弦

「定弦方案」面板（手机上是一个标签页，桌面上在右栏）包括：

- **预设**：标准调弦、Drop D 降六弦、全体降半音、全体降全音、开放 G 调弦、开放 D 调弦、DADGAD 凯尔特。
- **十二平均律模式**：匹配十二平均律里的任意音，不限于六根弦。
- **逐弦设音**：每根弦都可以设成 E1 到 E5 之间的任意音，可以保存成自定义方案，也可以重置回所选预设。

设置和自定义方案保存在浏览器的 `localStorage` 里。

## 音准检查

「音准检查」标签页用来检查每根弦在高把位是否准。12 品的音应该正好比空弦高一个八度。

1. 先把这根弦调准，在弦列表里选中它，点「开始检查 N 弦」。
2. 弹空弦，让它自然延音。音高稳定约 0.6 秒后自动读数。
3. 按住 12 品再弹一次，同样让它延音。

结果是 12 品相对八度的偏差音分，±3 ¢ 以内算合格。超出时会提示鞍座往后移（12 品偏高）还是往前移（偏低），并按 648 mm 弦长估算移动距离，约 0.37 mm/音分。检查需要麦克风。听到的弦或品位不对、或空弦偏差超过 10 ¢ 时会提示。

## 校准

| 设置 | 范围 |
|---|---|
| A4 基准音 | 430–450 Hz，步进 1 Hz，快捷选项 432 / 440 / 442 Hz |
| 变调夹 | 0–7 品，目标音随之升高相同的半音数 |
| 音准容差 | ±2 ¢（专业）、±4 ¢（标准）、±8 ¢（宽松） |
| 记号 | 升号（`#`）或降号（`b`） |
| 界面语言 | 中文或 English。第一次打开时跟随浏览器语言，顶栏的「中 / EN」按钮可以切换 |

## 节拍器

- 30–240 BPM，滑块加 −5 / −1 / +1 / +5 按钮，默认 90。
- 点击测速，并显示当前速度对应的速度术语（Largo、Andante、Allegro 等）。
- 拍号 4/4、3/4、2/4、6/8、5/4、7/8，有节拍指示，第一拍可以加重音。
- 每一拍都按 `AudioContext.currentTime` 提前排好，界面卡顿时节奏也不会漂。

## 检测原理

1. 麦克风信号先经过 65–1150 Hz 带通滤波，去掉风噪、低频嗡声和拨片摩擦声。
2. 用 YIN 算法估计基频，再在周期的整数倍上精修周期，并检查候选值，避免低音弦出现八度误判。
3. 电平门限（`src/utils/signalGate.ts`）只在拨弦瞬间之后才开始一次新读数。持续的背景声没有拨弦起音，所以会被忽略。
4. 结合 A4 和变调夹设置，把频率匹配到最近的目标弦（或十二平均律里的音）。

## 屏幕常亮

麦克风监听、试音模拟、节拍器或持续参考音运行时，屏幕不会自动熄灭。网页版在浏览器支持时使用 Screen Wake Lock 接口，Android 应用打开期间保持屏幕常亮。

## 离线与安装

网页版是带 Service Worker 的 PWA，第一次打开后就能离线使用，也可以安装到主屏幕。见[安装](install.md)。
